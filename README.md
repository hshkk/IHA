IHA (**I**nferential **H**armonic **A**nalysis) is an external domain-specific language for musical composition and elementary inferential harmonic analysis,
created as part of CS 585 (Domain-Specific Languages) in Spring 2025 at Oregon State University.

There are many issues with the implementation, especially concerning the efficiency of the inference algorithm and correctness of the parser. The work is provided here only for reference and documentation.

Files demonstrating syntax and core operations can be found [here](test) with the extension `.iha`.
